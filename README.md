    <h1>NORMAL ENDING</h1>
    <p><strong>Q：翻译这段摩斯密码</strong></p>    <p>10/111/010/11/01/0100//0/10/100/00/10/110</p>
    <p><strong>A：</strong>这段摩斯密码可以分解为以下部分：</p>
    <pre>
10 / 111 / 010 / 11 / 01 / 0100 // 0 / 10 / 100 / 00 / 10 / 110
    </pre>
    <p>假设数字 <strong>1</strong> 代表“-”（划），数字 <strong>0</strong> 代表“.”（点），我们可以将其转换为标准的摩斯电码：</p>
    <pre>
10 = -.  
111 = ---  
010 = .-.  
11 = --  
01 = .-  
0100 = .-..  
// = 分隔符（单词之间的空格）  
0 = .  
10 = -.  
100 = -..  
00 = ..  
10 = -.  
110 = --.
    </pre>
    <p>将这些摩斯电码转换为字母：</p>
    <pre>
-. = N  
--- = O  
.-. = R  
-- = M  
.- = A  
.-.. = L  
// = 空格  
. = E  
-. = N  
-.. = D  
.. = I  
-. = N  
--. = G
    </pre>
    <p>因此，翻译后的文本是：</p>
    <p><strong>NORMAL ENDING</strong></p>
    <p>这是一个有意义的英文短语，意思是“正常的结束”。</p>
